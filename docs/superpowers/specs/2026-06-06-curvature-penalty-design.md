# 曲率惩罚奖励设计

## 目标

惩罚机器人在走廊出生点持续转圈的行为，同时不干扰正常避障转弯和直行。

## 公式

```
r_curvature = -λ · ω_z² / (v_xy² + σ²)
```

| 符号 | 含义 | 来源 |
|------|------|------|
| ω_z | 机体偏航角速度 | `self.base_ang_vel[:, 2]` |
| v_xy | 水平线速度模长 | `torch.norm(self.base_lin_vel[:, :2], dim=1)` |
| λ | 惩罚强度 | 0.05 |
| σ² | 软化项（防零速爆炸） | 0.49 (σ = 0.7, 指令线速度中位数) |

物理意义：惩罚瞬时路径曲率平方 κ² = ω_z²/v_xy²，即轨迹偏离直线的程度。

## 数值验证

| 场景 | v (m/s) | ω (rad/s) | 每秒惩罚 | 30s episode |
|------|---------|-----------|---------|-------------|
| 正常直行 | 0.75 | 0.1 | -0.0005 | -0.015 |
| 缓弯避障 | 0.5 | 0.5 | -0.017 | -0.5 (持续) |
| 锐弯避障 | 0.5 | 1.0 | -0.07 (瞬态) | ~ -0.07 (1s) |
| 绕小圈 | 0.4 | 2.0 | -0.31 | -9.2 |
| 原地转 | 0.1 | 2.0 | -0.40 | -12.0 |

## 与现有奖励的交互

- **vel_avoid (2.0)**：避障转弯时依然跟踪 v_cmd + v_avoid，不会因曲率惩罚而失效
- **collision (-0.1)**：1 步碰撞惩罚远大于整 episode 避障转弯曲率成本，机器人不会因曲率惩罚而选择撞墙
- **rays (1.5)**：正向拉力远离墙壁，与曲率惩罚方向一致

- 配置：`scales.curvature = -0.05`，`go2_lidar_pd_risknet_config.py`
