# 指令优先 + 扇区约束速度：奖励重构设计

## 动机

现有 Omni-Perception 奖励设计以"自主避障 + 探索开阔空间"为目标：
- `vel_avoid`：将 v_avoid（远离障碍物的排斥向量）叠加到速度目标上，把机器人"推开"
- `rays`：计算开阔空间方向，奖励转向该方向的角速度，把机器人"拉向"空旷处

新任务目标：**指令优先，避障次之**。机器人应严格执行命令，在被命令的方向上贴着障碍物走、在指定位置停下，而非主动寻找开阔空间。

## 核心设计理念

**障碍物不应决定机器人"往哪走"，只应约束"在该方向上能走多快"。**

```
旧: cmd → 加入 v_avoid 偏移 → 实际速度目标
新: cmd → 每个方向分量 × 该方向安全因子 → 安全速度目标
```

## 点云预处理：双层 z 坐标过滤

在计算扇区距离之前，过滤掉身体帧中 z 坐标不在有效范围的射线：

```
对每条射线 i (在 avoid_distances 计算中):
    如果 lidar_points_base[i, 2] > z_thresh_high:
        忽略此点 (设置为 max_distance，不参与扇区 min())
    如果 lidar_points_base[i, 2] < z_thresh_low:
        忽略此点 (设置为 max_distance，不参与扇区 min())

z_thresh_high = 0.10    (身体帧，头顶 + 3.3cm 余量)
z_thresh_low  = -0.20   (身体帧，身底 - 14cm 腿部活动空间)
```

### 机制 1：头顶 z 过滤 → 被动蹲下引导

```
障碍物悬在 0.42m 高 (紧贴头顶上方 1cm):

  站立 (base_height=0.34):
    杆 z = 0.42 - 0.34 = 0.08  → z < 0.10, 被计入 → 惩罚! → 需要蹲下!

  蹲下 (base_height=0.22):
    杆 z = 0.42 - 0.22 = 0.20  → z > 0.10, 被过滤 → 无惩罚! → 通过!

障碍物悬在 0.50m 高 (头顶上方 9cm):

  站立 (base_height=0.34):
    杆 z = 0.50 - 0.34 = 0.16  → z > 0.10, 直接过滤 → 正常走, 不需蹲 ✓
```

### 机制 2：地面 z 过滤 → 身体高度自调节

```
站立 (base_height=0.34):  地面 z = -0.34 < -0.20 → 过滤 ✓, 无地面惩罚
走路 (base_height=0.28):  地面 z = -0.28 < -0.20 → 过滤 ✓ (6cm 振荡余量)
半蹲 (base_height=0.24):  地面 z = -0.24 < -0.20 → 过滤 ✓ (腿部空间充足)
过度低 (base_height=0.14): 地面 z = -0.14 > -0.20 → 计入! → 惩罚! → "别蹲那么低!"
```

**两个过滤形成双向软约束：**
- 头顶有障碍物 → 蹲下使头顶点消失 → 前进奖励恢复
- 蹲太低 → 地面点进入 → 惩罚 → 停止继续下蹲
- 策略在两者之间找到最优身体高度，不需要 `base_height` 奖励

### 安全保证：墙壁不被误过滤

从地面延伸到高处的墙，点云跨越整个 z 范围。即使顶部 z > 0.10、底部 z < -0.20 被过滤，中间区段 z ∈ [-0.20, 0.10] 始终参与计算，墙壁不会被漏掉。

## 核心公式：cmd_safe_vel

### Step 1: 逐扇区身体半径

Go2 身体近似为椭圆：半长 a = 0.188m (碰撞盒 L/2)，半宽 b = 0.047m (碰撞盒 W/2)。LiDAR 在 (0, 0)。

对每个扇区 j（方向角 θ_j）：

```
解方程: (r*cos(θ))²/a² + (r*sin(θ))²/b² = 1
→ body_radius_j = a*b / sqrt(b²*cos²(θ) + a²*sin²(θ))
```

36 个常数预计算，不参与运行时计算。有效距离 `d_eff_j = d_j - body_radius_j` 表示从身体表面到障碍物的实际间隙。

### Step 2: 扇区安全因子

```
d_eff_j = max(0, d_j - body_radius_j)                   -- 从身体表面起算的有效距离
safe_j  = clamp((d_eff_j - d_safety) / (d_safe_max - d_safety), 0, 1)

d_safety   = 0.10   -- 额外安全间隙
d_safe_max = 1.0    -- 超过此距离视为完全安全
```

### Step 3: 命令方向 2D 安全速度

```
cmd_2d = commands[:, :2]   # 基座帧
cmd_norm = ||cmd_2d||

对每个扇区 j:
    align_j = max(0, dot(cmd_2d, sector_center_j))   # cmd 在该方向的分量
    v_safe_2d += safe_j * align_j * sector_center_j   # 安全因子缩放

v_safe_2d = clamp_norm(v_safe_2d, max=cmd_norm)      # 不超过命令速度
```

### Step 4: 奖励

```
v_actual = base_lin_vel[:, :2]
r_cmd_safe_vel = exp(-||v_actual - v_safe_2d||² / σ²)

σ = 0.25
```

### 行为推演

| 场景 | v_safe_2d 行为 | 策略表现 |
|------|---------------|----------|
| 开阔地 + cmd=1.0 向前 | safe≈1 对所有前方扇区，v_safe≈cmd | 全速跟指令 |
| 窄通道 + cmd=1.0 向前 | 侧面扇区 safe≈0.4，v_safe 整体略降 | 减速通过 |
| 右墙 + cmd=[0.8, 0.3] | 前进分量保留，右向分量被抑制 | 沿墙滑行，不撞墙 |
| 前方 0.5m 墙 + cmd=1.0 向前 | 前方扇区 safe≈0，v_safe≈0 | 减速到几乎停止 |
| cmd=0（停车） | v_safe=0，任何移动都远离目标 | 停住 |

## 辅助公式：sector_dist_penalty

对所有 36 个扇区生效的全向背景惩罚：

```
r_dist = -α * mean_j(relu(d_thresh - d_eff_j)²)

d_thresh = 0.5m
α = 0.5
```

提供早期的"接近障碍物"预警信号。全向生效（包括后方），防止任何方向的贴墙依赖。

## 身体高度自调节

通过双层 z 过滤（高阈值 0.10 + 低阈值 -0.20），`base_height` 奖励可以移除。策略的身高选择由障碍物环境驱动：

- 头顶障碍物 → 下蹲使其 z > 0.10 → 过滤 → 前进奖励恢复
- 蹲太低 → 地面 z > -0.20 → 计入惩罚 → 停止下蹲
- 无头顶障碍物 → 地面一直被过滤 → 策略自由选择舒适高度

这是一个被动的自调节机制，无需显式的身体高度目标奖励。
