# vel_avoid 引导式避障奖励重新设计

## 问题

当前 `_compute_v_avoid` 将 36 个扇区的避障速度直接向量求和。在走廊场景中，左右两侧墙壁同时激活多个扇区，左右推力叠加导致 `v_avoid` 幅值过激。一旦机器人被推向一侧，另一侧墙壁立即产生反向推力，形成振荡，机器人最终不知道往哪里走。

## 目标

将避障逻辑从"推开"改为"引导"：
- 保留向量求和的平滑方向过渡
- 用指令方向投影区分威胁优先级（正前方 > 侧面）
- 用加权平均替代加权求和，使 |v_avoid| ≤ ||v_cmd||，无论多少扇区激活都不会超过指令速度
- 每个扇区权重 `cos_i+c ∈ [c, 1+c]`，方向自然平滑，无需软截断

## 最终公式

```
v_cmd_dir = v_cmd / ||v_cmd||                     (若 ||v_cmd|| == 0, v_avoid = 0)

每扇区 i = 0..35:
  u_i     = [cos(θ_i), sin(θ_i)]                  扇区中心方向
  cos_i   = max(0, v_cmd_dir · u_i)               指令在扇区方向的投影, [0, 1]
  d_i     = 扇区 i 内最小障碍距离
  w_i     = (cos_i + c) × exp(-alpha × d_i) × (d_i < d_max)

v_avoid = ||v_cmd|| × Σ w_i × (-u_i) / (Σ w_i + ε)
```

### 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| c | 0.0 | 侧面兜底推力比例（当前设为 0，邻扇区 cos>0 自动补位） |
| alpha | 1.0 | 距离衰减系数，复用现有 avoid_alpha |
| d_max | 1.5 | 截断距离(m)，复用现有 avoid_distance_thresh |
| n_sectors | 36 | 不变 |
| avoid_beta | 1.0 | 不变 |

### 为什么加权平均

- 加权平均天然上界：|v_avoid| ≤ ||v_cmd||，无论多少扇区同时激活，避障速度永不超指令速度
- 稀疏威胁（单根柱子）：只有一个扇区有显著权重，加权平均 ≈ 该扇区的 away_dir，幅值 ≈ ||v_cmd||
- 密集威胁（靠近长墙）：多个扇区权重相近，平均方向指向远离墙体密集侧，幅值仍 ≤ ||v_cmd||
- `cos_i` 的 max(0) 截断只保留前方半球，后方墙壁完全不影响合方向
- c=0 时，前方半球内相邻扇区天然 cos > 0 提供兜底推力，无需 c 参数

### 平滑性分析

- **方向**：加权求和天然平滑，威胁从扇区 A 逐渐转移到扇区 B 时合方向连续旋转
- **幅值**：`w_i` 上限为 `1+c`，近处不会像纯指数 `exp(-d)` 那样爆炸增长
- **cos_i 截断**：单个扇区在 90° 处从正变 0，但 36 扇区 10° 粒度平滑了该效应

### 关键场景行为

| 场景 | cos_i | d_i | w_i | 效果 |
|------|-------|-----|-----|------|
| 走廊中央前进 | 侧墙≈0 | 大 | ≈0 | 不干预 |
| 贴左墙前进 | 邻扇区>0 | 小 | 邻扇区自动激活 | 指向远离墙壁，幅值≤||v_cmd|| |
| 指令指向墙壁 | ≈1 | 中 | (1)×exp(-αd) | 强修正，幅值≤||v_cmd|| |
| 正前方柱子 | ≈1 | 很小 | ≈1 | 最强推开，幅值=||v_cmd|| |
| 凹形弯道 | 两侧墙≈0.5 | 小 | 加权平均指向开阔方向 | 自然避开密集侧 |

## 参数调优指南

- `c`：机器人贴墙时的推开幅度。太小 → 擦墙甚至卡墙；太大 → 回归振荡
- `d_max`：远距离截断。减小 → 更早响应近处障碍；增大 → 更远预判。可尝试 2.0~10.0
- `alpha`：距离敏感度。增大 → 更陡峭的近处响应；减小 → 更平缓
