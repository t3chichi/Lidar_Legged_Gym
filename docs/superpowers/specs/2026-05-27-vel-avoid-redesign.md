# vel_avoid 引导式避障奖励重新设计

## 问题

当前 `_compute_v_avoid` 将 36 个扇区的避障速度直接向量求和。在走廊场景中，左右两侧墙壁同时激活多个扇区，左右推力叠加导致 `v_avoid` 幅值过激。一旦机器人被推向一侧，另一侧墙壁立即产生反向推力，形成振荡，机器人最终不知道往哪里走。

## 目标

将避障逻辑从"推开"改为"引导"：
- 保留向量求和的平滑方向过渡
- 用软截断消除多扇区幅值叠加
- 用指令方向投影区分威胁优先级（正前方 > 侧面）
- 贴近障碍时提供轻柔兜底推力，而非剧烈弹开

## 最终公式

```
v_cmd_dir = v_cmd / ||v_cmd||                     (若 ||v_cmd|| == 0, v_avoid = 0)

每扇区 i = 0..35:
  u_i     = [cos(θ_i), sin(θ_i)]                  扇区中心方向
  cos_i   = max(0, v_cmd_dir · u_i)               指令在扇区方向的投影, [0, 1]
  d_i     = 扇区 i 内最小障碍距离
  active  = d_i < d_max
  w_i     = (cos_i + c) × exp(-alpha × d_i) × active

v_avoid_raw = ||v_cmd|| × Σ w_i × (-u_i)

mag_raw   = ||v_avoid_raw||
mag_cap   = max(w_i) × ||v_cmd|| + ε
v_avoid   = v_avoid_raw / (1 + mag_raw / mag_cap)
```

### 参数

| 参数 | 值 | 说明 |
|------|-----|------|
| c | 0.15 | 侧面兜底推力比例，占指令速度的 15% |
| alpha | 1.0 | 距离衰减系数，复用现有 avoid_alpha |
| d_max | 1.5 | 截断距离(m)，复用现有 avoid_distance_thresh |
| n_sectors | 36 | 不变 |
| avoid_beta | 1.0 | 不变 |

### 平滑性分析

- **方向**：加权求和天然平滑，urgency 从扇区 A 逐渐转移到扇区 B 时合方向连续旋转
- **幅值**：软截断 `x/(1+x/cap)` 光滑可导，无硬截断跳变
- **近处饱和**：`w_i` 上限为 `1+c`，近处不会像纯指数 `exp(-d)` 那样爆炸增长
- **cos_i 截断**：单个扇区在 90° 处从正变 0，但 36 扇区 10° 粒度平滑了该效应

### 关键场景行为

| 场景 | cos_i | d_i | w_i | 效果 |
|------|-------|-----|-----|------|
| 走廊中央前进 | 侧墙≈0 | 大 | ≈0 | 不干预 |
| 贴左墙前进 | 侧墙≈0 | 小 | ≈c | 轻柔右推，15% |
| 指令指向墙壁 | ≈1 | 中 | (1+c)×exp(-αd) | 强修正 |
| 正前方柱子 | ≈1 | 很小 | ≈1+c | 最强推开 |
| 走廊中偏左右 | 左右接近反向 | 左右接近 | 方向指向弱侧 | 方向正确，幅值受限 |

## 参数调优指南

- `c`：机器人贴墙时的推开幅度。太小 → 擦墙甚至卡墙；太大 → 回归振荡
- `d_max`：远距离截断。减小 → 更早响应近处障碍；增大 → 更远预判。可尝试 2.0~10.0
- `alpha`：距离敏感度。增大 → 更陡峭的近处响应；减小 → 更平缓
